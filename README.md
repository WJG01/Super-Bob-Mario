# 🤖 Super-Bob-Mario User  Manual

An endless runner where you guide IBM Bob through a city of skyscrapers, bugs, and firewalls, collecting boosters along the way.

## 🎮 Controls

| Action | Input |
|--------|-------|
| Jump | `SPACE` / `↑` / Click |
| Duck | `↓` |
| Restart | Click on Game Over screen |

## 🦸 The Hero: IBM Bob

- Drawn entirely with **Canvas**
- Blue hard-hat with gradient, `</>` apron badge, blinking eyes, and ear panels
- Animated walking legs and arms
- **Ducking mechanic** (`↓`) squashes him down to dodge low obstacles
- **Jump** with `SPACE`, `↑`, or Click

## 🏙️ Obstacles

| Obstacle | Description |
|----------|-------------|
| **Buildings** | Tall IBM-blue skyscrapers with animated twinkling windows and a rooftop antenna |
| **Bugs** 🐛 | Red flying creatures with flapping wings that bob up and down |
| **Firewall** 🔥 | Pulsing red wall with a `FIREWALL` label, narrow but deadly |

## ⚡ Boosters

Floating gems that give Bob a temporary edge:

| Booster | Effect |
|---------|--------|
| ⚡ **Speed** | Turbo mode: the world scrolls faster and Bob zooms with a yellow trail |
| 🚀 **Jump** | Super-jump height and glowing green eyes |
| 🛡️ **Shield** | Absorbs one hit, with a purple ring orbiting Bob |
| 💎 **Points** | Instant +100 score burst |

## 🎯 Game Features

- **Infinite scrolling** with speed increasing each level
- **Lives system**: 3 hearts, with invincibility frames after hits
- **Particle effects** on jumps, boosts, and collisions
- **Level progression**: gets harder every 300 points
- **Game Over screen** with click-to-restart
