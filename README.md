# Super-Bob-Mario
ABOUT: The perfect high-adrenaline, stress-relieving game for when you're stuck debugging code. (Only if you are a fan of IBM Bob)



🤖 Super-Bob-Mario
Drawn entirely with Canvas: blue hard-hat with gradient, </> apron badge, blinking eyes, ear panels, animated walking legs & arms
Ducking mechanic (↓ key) squashes him down to dodge low obstacles
Jump with SPACE / ↑ / Click
🏙️ Obstacles (3 types)
Obstacle	Description
Buildings	Tall IBM-blue skyscrapers with animated twinkling windows & rooftop antenna
Bugs 🐛	Red flying creatures with flapping wings that bob up and down
Firewall 🔥	Pulsing red wall with FIREWALL label — narrow but deadly
⚡ Boosters (4 types, floating gems)
Booster	Effect
⚡ Speed	Turbo mode — world scrolls faster, Bob zooms with a yellow trail
🚀 Jump	Super-jump height + glowing green eyes
🛡️ Shield	Absorbs one hit, purple ring orbits Bob
💎 Points	Instant +100 score burst
🎯 Game Features
Infinite scrolling with increasing speed per level
Lives system (3 hearts) with invincibility frames after hits
Particle effects on jumps, boosts, and collisions
Level progression — gets harder every 300 points
Game Over screen with restart on click
